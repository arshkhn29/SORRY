Aaj se aap meri sis aur frnd hai. Mujhe aapse sorry bhot dino se bolna tha par mujhe laga ki aap mere se baat nahi karoge isiliye maine aapko ye letter diya hai. Main dil se maafi maangta hun please mujhe maaf kardijiye. Aapka sukrguzaar rahunga.

Jaisa aap mere baare main सोचते ho main aesa nahin hu. Main sayad baki logon se different hun. Mujhe bhot baar Class 9th main aana hota hai, lekin main isiliye nahi aata kabhi aap kuch galat samjo.

School ke dost

Main vese toh school main har kisi bacche se thoda bhot bol leta hun. Lekin mere do sabse khaas insaan class 9th main hai — ek Ali jo bhai jesa hai aur ek Sarfaraz jo jigri yaar hai 3 saalon se (aur Ali toh bhot saalo se saath hai).

Bhot baar mujhe aesa lagta hai ki jab mai aapke aas paas hota hun toh aapko accha nahin lagta. Isiliye main aapse doori banane ki koshish karta hun lekin tum utne hi paas aa jate ho pata nahi kyon.

Maine kabhi kisi ladki ko aaj tak proposal nahi bhja, sirf tum hi ek phli ladki ho jisko mene proposal bhja tha. Pata nahi mujhe kya ho gaya tha main kabhi bhi aese kaamon main nahi pada. Main toh ek seedha se ladka,maasum sa Hafiz-e-Quran hun. Lekin pata nahi shaitan ne kya kara mere saath jo mene aapko proposal bhja.

Maine ye letter isiliye likha hai jisse aapko pata lag jaye ki mera koi galat irada ya galat behaviour nahi hai aapke saath. Main aesa wesa ladka nahi hun
